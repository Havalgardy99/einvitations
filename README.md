# بانگهێشتنامەی دیجیتاڵی — Digital Wedding Invitation

سیستەمێکی تەواو بۆ بانگهێشتنامەی هاوسەرگیریی دیجیتاڵی لەگەڵ **داشبۆردی بەڕێوەبەر** و **لینکی تایبەت** بۆ هەر ئەکاونتێک.

## تایبەتمەندییەکان

- داشبۆردی بەڕێوەبەر لە `/admin`
- زیادکردنی ئەکاونتی نوێ → لینکی تایبەت خۆکار درووست دەبێت (`/i/slug`)
- هەر ئەکاونت تێمپلەیتێکی تایبەتی خۆی هەیە (ناو، بەروار، شوێن، بەرنامە، وێنە، …)
- RSVP و پیرۆزبایی لە سێرڤەردا پاشەکەوت دەبن

## دەستپێکردن

```bash
npm install
cp .env.example .env.local
# ADMIN_PASSWORD لە .env.local بگۆڕە
npm run dev
```

- **داشبۆرد:** http://localhost:3000/admin  
- **نموونەی بانگهێشت:** http://localhost:3000/i/daniel-elira  

## بەکارهێنان

1. بچۆ بۆ داشبۆرد و بە `ADMIN_PASSWORD` بچۆ ژوورەوە.
2. «ئەکاونتی نوێ» درووست بکە (ناوی ئەکاونت وەک «هەور»).
3. لینکی تایبەت کۆپی بکە و بۆ میوانان بنێرە.
4. هەموو دەق و وردەکارییەکان لە بەشی دەستکاری بگۆڕە.

## Production

```bash
npm run build
set NODE_ENV=production
npm run start
```

سێرڤەر لە پۆرتی `3001` API و فایلی `dist` دەخوێنێتەوە.
